隐私政策

本政策说明 Toolathlon Evaluation 独立研究接入如何访问、使用、传输和保存 Google 数据。

更新于 2026-11-13 · 操作者联系邮箱：mirarchibowery@gmail.com

1. 应用、账号与数据来源

本程序用于操作者明确授权的 Toolathlon 工具任务、reset 验证和审计。应使用专用测试账号及获准使用的任务数据，避免接入个人或生产业务数据。

Google 授权由账号持有人完成。授予的权限可能覆盖账号内较广的资源；具体执行范围仍需由任务配置、运行程序和操作者确定。任务初始化、写入与 reset 应在专门测试资源上完成对应验证后运行。

2. 访问哪些数据和权限

服务任务可能访问或操作的数据
Google Drive文件与文件夹的元数据、任务文件内容，以及明确授权的新建、修改或删除操作。
Google Sheets电子表格结构、工作表、单元格和任务要求的读写操作。
Google Forms表单内容与结构管理，以及表单响应读取。响应权限为只读。
Google Calendar日历列表、事件内容，以及明确授权的测试资源操作。

程序还会保存 OAuth 客户端配置、Refresh Token、临时 Access Token 和相关授权范围，以便在授权有效期间执行任务。凭据通过操作者管理的私有配置保存和传递，不应进入公开网页、代码仓库或公开运行产物。

3. 数据用途与模型服务

Google 数据用于执行明确的工具任务、准备和验证业务初态、进行 reset 验证，并核查工具调用和任务运行结果。

Google 内容及其聚合、变换或派生轨迹仅用于上述执行和审计用途，不用于模型训练或蒸馏训练，不应纳入相应训练数据集。

执行期间，工具返回的 Google 内容可能作为任务上下文，经执行程序和 LiteLLM 发送给操作者配置的模型服务，用于完成本次任务。模型服务由操作者选择，其接收和保留数据的行为还受该服务的配置与政策约束。连接账号前应了解所配置的模型服务。

本接入不以广告或出售用户数据为目的。对 Google 数据的使用应符合 Google API Services User Data Policy，包括适用的 Limited Use 要求。

4. 保存位置、访问与保留

完整模型请求、工具调用与返回、模型响应、工作区文件、诊断日志和业务状态快照可能含有 Google 原始内容。它们保存在操作者管理的本地工作区、执行服务器或运行存储中。

运行容器或沙箱可能在任务后销毁；这不代表宿主导出的轨迹、工作区和远端测试资源同时被删除。历史任务对象和运行记录可能继续保留用于核查，需由操作者单独清理。本程序不承诺一个已经自动实施的统一清理期限。

操作者负责限制运行存储、凭据和记录的访问范围。审计记录不应公开发布；需要分享运行证据时，应先处理其中的用户内容和秘密信息。

5. 撤销授权和删除请求

账号持有人可以在 Google 账号连接管理撤销本应用授权。撤权会阻止后续授权访问，不会自动清空已导出的文件、轨迹或历史测试对象。

如需清理这些记录或测试资源，请联系操作者并说明账号、任务或运行标识。操作者需根据实际存储位置检查和处理；无法承诺由本静态网页直接删除数据。

6. 本网站与政策更新

说明网站是 GitHub Pages 托管的静态页面，没有账号登录、密钥输入、上传表单、Google 业务 API 调用或统计脚本。托管平台可能依照其政策记录技术访问日志。

如 Google 数据用途、接收方或权限范围发生变化，应先更新说明，并在需要时重新取得账号持有人同意后使用。联系邮箱：mirarchibowery@gmail.com。
